# Mobile App

## Supported platforms
- Android 8.0 and above
- iOS 14 and above

## How to download
- Android: Search "Example App" on Google Play Store
- iOS: Search "Example App" on the App Store

## Features available on mobile
- View projects
- Create and edit simple items
- Receive notifications
- Offline mode for basic viewing

Advanced features such as bulk export and API management are only available on the web version.

## Login on mobile
Use the same email and password as the web version.
If you have 2FA enabled, you will need to enter the code from your authenticator app.
