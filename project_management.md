# Creating and Managing Projects

## How to create a new project
1. Click the "+ New Project" button on the dashboard.
2. Enter a project name (minimum 3 characters).
3. Optionally add a short description.
4. Click Create.
You can have up to 5 projects on the Free plan and unlimited on paid plans.

## Editing a project
- Click the three dots next to the project name.
- Select "Edit".
- Change the name or description.
- Save changes.

## Deleting a project
Deleting a project is permanent.
All data inside the project will be removed and cannot be recovered.
Only the project owner can delete a project.

## Sharing a project
On the Team plan you can invite members by email.
Invited members can view and edit the project depending on the permission you give them (Viewer or Editor).

## Project limits
Free plan: maximum 5 projects.
Pro and Team plans: unlimited projects.
If you reach the free limit you must upgrade or delete an existing project.
