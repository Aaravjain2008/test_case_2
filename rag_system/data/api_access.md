# API Access

## Who can use the API
API access is available on Pro and Team plans only.
Free plan users cannot generate API keys.

## How to create an API key
1. Go to Settings → Developer.
2. Click "Generate New API Key".
3. Give the key a name (for example "My App").
4. Copy the key immediately. You will not be able to see it again.
5. Store the key securely. Never share it publicly.

## Rate limits
- Pro plan: 100 requests per minute
- Team plan: 500 requests per minute

If you exceed the limit you will receive a 429 error.
Wait one minute and try again.

## Revoking a key
If a key is leaked or no longer needed:
1. Go to Settings → Developer.
2. Find the key and click "Revoke".
The key stops working immediately.
